# Example results (analysed with Meta Muse Spark 1.3)

- `demo-invoice-processing/`: the synthetic accounts-payable demo (`python -m flowsme demo`). Open
  `analysis/report.html` in a browser. Everything in it is made up, including the screenshots.
- `real-ap-invoice-test/`: a real 4-minute recording of copying invoices from Notepad into an Excel tracker,
  done on a Windows PC with real mouse and keyboard input. It includes mistakes and corrections, which the
  analysis detects. Only the text report and data are included: the screenshots show a real desktop, so
  they stay on the machine that recorded them.

Customer tools used for both: Microsoft 365, Power Automate, Power BI.
